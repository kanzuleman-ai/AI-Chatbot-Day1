# AI-Chatbot-Day1

A basic conversational AI chatbot built with Python and Google's Gemini API.

## What I Built

I built a simple AI chatbot that accepts user messages, sends them to Google's Gemini API, and displays AI-generated responses. The chatbot also maintains conversation history to provide context-aware replies.

## Technologies Used

* Python
* Google Gemini API
* Google Colab

## How to Run

1. Open the notebook in Google Colab.
2. Add your Gemini API key as a Colab Secret named `GEMINI_API_KEY`.
3. Run the Gemini connection cell.
4. Run the chatbot cell.
5. Enter messages in the chat.
6. Type `exit` to end the conversation.

## API Integration Approach

The chatbot uses Google's Gemini API through the Python Google GenAI SDK. The API key is securely accessed from Google Colab Secrets. User messages and conversation history are sent to the Gemini model, which generates a response that is displayed in the chatbot.
