# AI-Chatbot-Day1

A basic conversational AI chatbot built with Python and Google's Gemini API.

## Features

* AI-generated responses
* Conversation history
* Context-aware conversations
* Continuous interaction
* Exit command

## Technologies

* Python
* Google Gemini API
* Google Colab

## How It Works

1. The user enters a message.
2. The message is sent to the Gemini API.
3. Gemini generates a response.
4. The chatbot displays the response.
5. Previous messages are maintained as conversation history.

## Project Purpose

This project was developed as part of my AI internship to learn API integration, conversational AI, and basic Python implementation.
